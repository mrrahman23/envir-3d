## Pipeline

- **Geodata:** `node scripts/fetch-geodata.mjs` (NASA BMNG, Sentinel-2 L2A via Earth Search STAC, Copernicus DEM GLO-30; needs geotiff — see the script header). Georeferencing in `public/assets/geo/geo.json`.
- **Hero posters and detail DEM:** `node scripts/bake-hero-posters.mjs [posters|dem]` against a running dev server.
- **Geology scans:** `node scripts/fetch-geology.mjs` (Poly Haven API → 1024²/512² WebP).
- **GLB stones:** `gltf-transform optimize <in>.gltf <out>.glb --compress meshopt --texture-compress webp --texture-size 256 --simplify true --simplify-ratio 0.02 --simplify-error 0.03 --join false`. Three.js decodes meshopt natively; there's no Draco decoder download.
- **Earth atlas:** `node scripts/bake-earth.mjs <dir-with-polyhaven-1k-jpgs>`.
- **Product renders and scene posters:** `BASE=http://localhost:3000 node scripts/render-assets.mjs [materials|posters]` against `npm run dev`.
- **Icons:** process icons are inline SVG React components (`src/components/diagrams.tsx`) so they inherit colour and need no requests; `public/assets/icons/` is intentionally empty.
